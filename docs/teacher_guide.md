# 教师操作

启动 ./run.sh seed:=11；换种子需重启或使用教师服务。
/final/reset 重置当前实例；/final/randomize 换题。
这些服务会改变仿真状态，学生算法不应调用。
/teacher/* 是验收真值，/final/status 和 /final/events 是公开裁判反馈。

当前场地为 2.75 m 缩放训练场，默认采用程序生成的训练外观。
详细旧网格、完整自动解题程序与历史录像只保留本地，并由 .gitignore 排除。
不要将完整解题程序放在公开学生分支；可以在教师私有仓库维护参考实现。

本地 ROS 1 没有按话题实施访问控制，隐藏解法源码也不等于防作弊。
正式评分须在教师控制的环境运行提交代码，并执行适当的进程/网络和文件访问隔离。
当前裁判只核验到点顺序/距离，不证明学生实际使用相机识别或执行了后退。

每次发布：检查模型授权 → 从干净 checkout 获取依赖、构建 → 原生相机与学生起降检查 →
教师私有参考程序多随机种子完整跑分 → 保存报告。
当前传感器为理想 IMU/GPS，不能将悬停表现当作真实 Tello 性能。
